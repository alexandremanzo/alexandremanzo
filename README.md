**[demo ao vivo · live demo](https://alexandremanzo.github.io/plataforma-dados-pessoais/)**

Plataforma de dados de ponta a ponta tratada como projeto corporativo: SQL Server
em arquitetura medalhão (bronze → silver → gold), ETL em Python idempotente,
orquestração no Airflow com Docker, testes de conciliação, glossário de dados no
próprio banco e um hub de painéis analíticos com simuladores. A demo roda com
dados fictícios.

*An end-to-end data platform built like a corporate project: SQL Server medallion
architecture (bronze → silver → gold), idempotent Python ETL, Airflow orchestration
on Docker, reconciliation tests, an in-database data glossary and a hub of analytical
dashboards with simulators. The demo runs on synthetic data.*
